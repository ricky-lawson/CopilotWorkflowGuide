# Copilot Workflow Transformation Guide

Static GitHub Pages export of the Copilot Workflow Transformation Guide managed app.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, open Settings > Pages.
3. Set Source to Deploy from a branch.
4. Select the main branch and / (root).

The site is a single-page app, so 404.html intentionally mirrors index.html for direct route support.
